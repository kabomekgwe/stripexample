# Payments Workspace

Monorepo with separate backend and frontend apps:

- `backend/` - NestJS billing API
- `frontend/` - Next.js in-app payments UI

## Run locally

```bash
pnpm install
pnpm dev
```

Default local URLs:

- Backend: `http://localhost:3000`
- Frontend: `http://localhost:3001`

## App-specific setup

- Backend env: `backend/.env.example`
- Frontend env: `frontend/.env.example`
